Bins Out — secure VAPID key generator

Creates the matching keys needed for automatic phone reminders.

Privacy: Keys are generated locally in this browser. This page does not send them to a server. Keep the private key secret; never paste it into GitHub or share it with anyone.

Cloudflare variable: VAPID_PUBLIC_KEY

2. Private key (secret)

Generate a pair, then add each value to the Cloudflare Worker settings. Store the private key as a secret.
