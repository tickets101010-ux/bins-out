BINS OUT — V#2 EMPTY-ADDRESS UPDATE

Based on V#1. Changes:
- The final saved address/household can be deleted.
- An intentionally empty household list stays empty; the app will not recreate a demo/default household.
- Empty state offers a clear way to add the first address later.
- Saving an address with no existing household creates the first household.
- Reminder preferences and demo preview handle the no-household state safely.
- Service worker cache updated to bins-out-v9.

UPLOAD:
1. Open https://github.com/tickets101010-ux/bins-out
2. Upload all files in this ZIP into the repository root.
3. Replace same-named files when prompted. Do not upload the ZIP itself or create a new folder.
4. Wait for GitHub Pages to publish.
5. If Android's app install is stuck, use the proven sequence: open site in Chrome, clear browser history, then reinstall the app icon.

This package does not update GitHub automatically; files must be uploaded there.
